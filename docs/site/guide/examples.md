# Examples

Worked examples are coming. Each one will be a complete, type-checked program you can copy
from, not a fragment.

## Planned

- **Blog tutorial.** A small app built step by step: schemas, a registration changeset,
  queries, preloads, a nested comment form, a batch to publish a post and notify
  subscribers, and tests.
- **Recipes.** Short answers to common tasks: offset and keyset pagination, soft deletes,
  upserts, find-or-create, optimistic locking, enums, a money type, full-text search,
  the top N rows per parent, filters built from a query string, and rendering changeset
  errors in a form.
- **Framework integration.** Using a repo in Express, Fastify, Hono and Next.js, and
  shutting down cleanly.

Until then, every guide page has examples for the feature it covers. Start with
[Getting started](/guide/getting-started).
